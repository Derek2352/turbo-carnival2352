FRAME 3Two-Function Architecture夾單 + 後數 = one ecosystem
ARCHITECTURE
Two new functions,
one ecosystem.
由「付款一刻」延伸到「持續關係」，由 transactional 到 social。
FUNCTION A
「夾單」
Split this bill
  • ▸One-off transactional split
  • ▸AI OCR auto-itemise (拍單)
  • ▸Tap-to-claim friend view
FUNCTION B
「後數」
Group ledger
  • ▸Persistent friend groups
  • ▸Running balance + history
  • ▸AI-optimised settle-up
夾單 feeds 後數
後數 saves split presets
One AI engine. One social graph.

Section 4 — 阿夾 ✦ The Group's Financial Co-Pilot

The reframe: AI isn't a feature added to splitting — it's a persistent agent living in every 飯腳 group. It anticipates, mediates, audits, remembers. The split itself is just the visible 1%.

THE REFRAME
